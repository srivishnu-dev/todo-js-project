# Simple JS Task Manager

Hey there! This is a simple, clean, and functional To-Do List application I built using Vanilla JavaScript. I wanted to create something that actually helps in managing daily tasks without any clutter.

## Features
- Add tasks quickly.
- Mark tasks as completed .
- Delete tasks when they are no longer needed.
- Persistent Storage: I used LocalStorage, so even if you refresh the page or close the browser, your tasks won't disappear.
- Responsive Design: Works fine on mobile and desktop.

## How to Run
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file in any modern web browser.
3. Start adding your tasks!

## Tech Stack
- HTML5 for the structure.
- CSS3 for styling (used a clean, modern look).
- Vanilla JavaScript for the logic and LocalStorage.
